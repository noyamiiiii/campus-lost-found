## 1. 要回答的三个问题

1. 现在东西丢了/捡到之后，**实际**是怎么处理的？谁参与，在哪交接？
2. 哪些环节真的浪费时间或造成纠纷？有没有人因此放弃寻找？
3. 一学期大概多少起？找回率、平均找回时间大概什么量级？

> 第 3 条如果拿不到真实数字，就在文档里写“待验证假设”，不要估一个数当结论。

## 3. 问题清单

原则：先问事实和经过，再问感受；不问“是不是因为群消息太乱”，而是问“当时你是怎么找的”。

### 3.1 学生版

1. 最近一次丢东西（或捡到东西）是什么时候？大概是什么物品？
2. 发现之后你做的第一件事是什么？接着做了什么？
3. 你在哪些地方发过消息？（班级群、宿舍群、校园墙、朋友圈、其他）
4. 从发消息到有结果，大概过了多久？中间你问过多少人？
5. 最后找到了吗？如果没找到，是什么时候放弃的？
6. 有没有遇到过“对方说的特征对不上”“约了地方人没来”这类情况？
7. 如果学校有个统一的失物招领入口，你最希望它先解决哪一件事？
8. 愿不愿意在平台上留联系方式？愿意留到什么程度（站内消息 / 手机号 / 只留学号）？

### 3.2 辅导员版

1. 一学期大概有多少学生找你问失物的事？主要是什么物品？
2. 信息一般从哪来？（群消息、学生私聊、班委汇总）
3. 你会帮忙核实身份或物品归属吗？怎么核实？
4. 有没有出现过冒领、纠纷或者隐私问题？
5. 现在最占用你时间的是哪一步？

### 3.3 服务点 / 保卫处版

1. 一个月大概收多少件？哪些类别最多？
2. 收到之后怎么登记？登记在本子、Excel 还是系统里？
3. 学生来认领时怎么核对？需要出示什么？
4. 多久清理一次长期无人认领的物品？怎么处理？
5. 有没有物品因为登记信息不全而一直找不到失主？

## 4. 记录规范

每次访谈当天填进 `调研记录.md`，字段固定：

- 编号（R01、R02…）、日期、对象角色（不写真实姓名，写“大三住宿生”这类描述）
- 是否同意引用原话
- 过程摘要（3–5 句，按时间顺序）
- 可引用原话（1–2 句，尽量逐字）
- 证据等级（A/B/C/D，见下）

证据等级：

| 等级 | 含义 | 用法 |
| --- | --- | --- |
| A | 后台数据、纸质台账、多人可复核的记录 | 可直接写进 D1 的“现状数据” |
| B | 3 人以上独立描述一致 | 可写成“调研显示”，注明样本量 |
| C | 单人回忆 | 只能作为线索，需交叉验证 |
| D | 团队推测 | 必须标注“待验证假设” |

## 6. 不要做的事

- 不要先写“平台上线后找回率提升 30%”，再倒推调研。
- 不要把“你觉得群消息是不是很乱”当问题，这是引导性提问。
- 不要把某一位同学的强烈抱怨当成普遍现象，至少 3 人一致才算 B 级。
- 不要在记录里写真实姓名、手机号、学号，只写角色描述。

## 3. 开发顺序

1. **公共基础**：统一响应、`traceId`、异常码、请求日志、前后端契约。
2. **持久层**：Flyway、MyBatis-Plus、MySQL 驱动；普通单元测试不依赖数据库。
3. **第一条纵向切片**：分类 → 公开帖子列表/详情 → 前端真实接口。
4. **登录与发布**：固定验证码登录、JWT、草稿与提交审核。
5. **主链路**：文件、识别降级、匹配、认领、核销与通知。

每一刀都必须同时包含契约、迁移、后端测试、前端状态和联调记录。未贯通前后端的模块不标记为完成。

## 4. 环境约定

- 本机已有 MySQL 占用 `3306`，项目容器统一使用 `3307`。
- `deploy/.env` 只保存本地覆盖值，不提交。
- Docker 依赖通过 `docker compose -f deploy/docker-compose.dev.yml` 启动。
- 数据库以容器内 MySQL 8.4.3 为开发基线，DDL 已在 2026-11-02 验证通过。
